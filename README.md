# Snake Water Gun Game

A simple Python console game where the player competes against the computer.

## Requirements

- Python 3.x

## How to Run

Open a terminal in this project folder and run:

```bash
python snake_water_gun.py
```

## How to Play

Choose one of:

- `snake`
- `water`
- `gun`

The game runs for 3 rounds.

## Rules

- Snake beats Water
- Water beats Gun
- Gun beats Snake
- Same choice = Tie
